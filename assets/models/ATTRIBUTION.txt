License: Creative Commons Attribution (CC BY), as listed on the Sketchfab model page.

Changes made for EscapeGame: removed the roof so the third-person camera can see
inside, merged static meshes by material to reduce draw calls, and kept the two
exit-door leaves separate so game state can open them. The original model and
textures are otherwise unchanged; the blackboard clue is a game-added overlay.

Vivi manga student style

License: Creative Commons Attribution-NonCommercial-ShareAlike (CC BY-NC-SA),
as listed in the model's embedded GLB metadata.

The original model and textures are bundled unchanged; a teammate added the
walking animation, and a Mixamo jump animation (same mixamorig skeleton) was
added alongside it by scripts/pack-player-animations.py (actions: Walking, Jumping, Idle; the jump is Mixamo
"Jump" and the idle is Mixamo "Standing Idle", played when the player stands still). The project scales the model to fit the classroom and uses
it as the human player character.
