## 2. 遊戲規則

### 2.1 核心機制：變身與互動
玩家不是「拿著」物品，而是**變成**物品。

1. **變身**：與可變身的物品互動，就會變成那個物品。
2. **以該形態互動**：用目前的形態去和其他東西互動，觸發對應事件。
   - 例：變成學生證 → 碰學院大門 → 大門打開
3. **進入特殊地點**：某些地點以人類的體型去不了，必須變成特定物品才能進入。
   - 例：變成飲料罐垃圾 → 鑽進飲料機裡面
4. **自身互動**：部分形態可以「與自己互動」，觸發專屬動作（例：骰子滾動、時鐘撥指針）。

互動可能的結果：出現新物品、變身、進入特殊地點、改變場景狀態、加血、扣血、解鎖成就、觸發結局、搞怪（無實際效果）。

### 2.2 變身規則
- **取得即可變身**：劇本中「拿到」的物品，都是指可以互動變成的物品。
- **人類身體**：每位玩家各自有一個人類身體。變身時，人類身體留在原地。
- **變回人類**：隨時可以，會回到人類身體所在的位置。
- **物品直接互換**：可以從一個物品形態直接變成另一個物品，原本的物品留在當時的位置與狀態。
- **物品仍在場景中**：變身後，那個物品仍存在於場景中，玩家等於「成為」它本身。
- **物品唯一**：每個物品同一時間只能被一位玩家變身。

### 2.3 生命值
- **全隊共用一條生命值**，所有形態共用。任何玩家扣血，都是扣全隊的血。
- **初始 5 血，沒有上限**，加血可以超過 5。
- 生命值歸零 → 全隊一起死亡，觸發 E05 壞結局，遊戲重啟。
- 所有加血、扣血來源見第 9.1 節。

### 2.4 時間
- 時限 **30 分鐘**，時間到 → 觸發 E04「天亮」。

### 2.5 多人遊玩
- **各自逃出**：一位玩家逃出（E01、E02、E03），就只有他自己逃出，其他玩家繼續遊戲。
- **逃生方法可重複使用**：有人逃出後，場景維持原狀（例：學生證留在大門旁、高窗保持開著），其他玩家可以用同一招再逃。
- **全隊結局**：E04 天亮、E05 死亡會套用到所有還沒逃出的玩家。
- **玩家之間不能互動**：不能和別人的人類身體互動，也不能和已變身的其他玩家互動。
- 監視器可以看到整張地圖，方便分工（見 6.6）。

### 2.6 無效組合
互動表中沒有定義的組合，一律彈出文字框：

> [對象]紋絲不動，好像在嘲笑你：「就這？你是認真的嗎？」

### 2.7 提示
- **不提供任何提示。**

### 2.8 遊戲目標
- **主要目標**：逃出學院。觸發任一好結局或特殊好結局即通關。
- **收集目標**：解鎖各種結局成就與搞怪成就（見第 8 節）。

## 3. 故事

### 前提
- 「我」是一名大學生，在**別的學院**上**密碼學**課，不是這個學院的學生。
- 我在課堂上睡著了，整場遊戲都是我的夢。故事就只有「睡著」這件事，不另外設計故事線索。

### 開場劇情
我在密碼學課上睡著了。

醒來時，竟然已經是晚上。學院的門被鎖住了。我不是這個學院的學生，根本不知道他們晚上會鎖門。看起來只有**刷學生證**或**知道密碼**才能出去。

於是我開始了一連串闖關，想找到一張學生證或密碼。

## 6. 關卡

### 6.1 第一關：密碼學教室

主角睡著的教室，剛上完密碼學。

- **離開教室**：教室門被鎖住了，要找一個夠重的東西把門撞開。
  - 變成**椅子**碰教室門 →「砰！」你用盡全力撞了上去，教室門被撞開了 → 可前往走廊。
  - 其他形態碰門 →「門被鎖住了，也許可以找個夠重的東西把它撞開」
- **黑板**（紅鯡魚）：老師留下的板書，寫著一題凱薩密碼 `WKH SDVVZRUG LV QRW KHUH`（位移 3，明文 THE PASSWORD IS NOT HERE，「密碼不在這裡」）。只是寫在黑板上的題目，不需要輸入答案。
- **骰子**：老師講亂數時用的教具。
  - 變成骰子後與自身互動 → 滾出隨機點數（1～6），跟大門密碼毫無關係。
  - 變成骰子碰講桌 →「你從講桌滾下去，摔得頭暈眼花」**-1 血**。碰黑板沒有特殊效果（預設回應）。
- **時鐘**：變成時鐘後與自身互動 → 把指針撥快 → 窗外天亮，觸發 **E04**，並解鎖 A06「時間管理大師」。
- **講桌抽屜**（紅鯡魚）：鎖著，整場遊戲都打不開。任何形態碰它 →「抽屜鎖得死死的，好像在說：『別白費力氣了，你永遠打不開我。』」

互動：X018、X020、X021、X029、X030、X036、X037（X028 已取消，編號保留不用）

### 6.2 第二關：走廊

- **垃圾桶**：人類翻垃圾桶 → 拿到**飲料罐垃圾**。
- **飲料機**：變成飲料罐垃圾 → 鑽進飲料機 → 拿到**飲料**。
  - 第一次變成飲料 **+1 血**；之後再變成飲料 →「喝太多，肚子痛」**-1 血**。
- **飲料機底下**：變成飲料罐垃圾 → 滾進飲料機底下 → 拿到**學生證**。
- **學院大門**：
  - 變成學生證碰大門 → 大門打開 → **E01**「撿到就是我的」。
  - 輸入四位數密碼 → 見 6.3。
- **花盆**：人類打翻花盆 →「花盆砸到了你的腳」**-1 血**，拿到**不知道用來做什麼的鑰匙**：「不知道為什麼會掉在花盆裡的鑰匙，可能可以打開某扇門」。變成鑰匙碰辦公室門 → 進入辦公室。
- **公布欄**（紅鯡魚）：「門禁密碼更改公告：即日起，新密碼為——」後面被撕掉了，只剩一角。

互動：X001～X005、X009、X010、X026、X031

### 6.3 密碼路線（E02）

- 大門可以輸入**四位數密碼**，但這是一個**假命題**：遊戲裡根本找不到密碼，沒有任何線索指向它。
- 玩家只能**暴力破解**。輸入錯誤不給任何提示（不提示大小、不提示哪幾位正確）。
- 輸入錯誤 →「門紋絲不動，好像有點死了」
- 每次輸錯，有 **1/1000 機率**觸發「手指抽筋了」**-1 血**（純運氣）。沒有次數上限。
- 輸入正確 → 大門打開 → **E02**「密室逃脫大神」。

互動：X016、X017

### 6.4 辦公室

**進入條件**：變成走廊花盆裡的鑰匙碰辦公室門。

- **辦公桌抽屜**：打開 → 拿到「**不知道用來做什麼的鑰匙**」，可以打開廁所的儲物間。
- **電腦**（紅鯡魚）：需要密碼才能登入，設計上永遠打不開。
- **牛皮紙包**：拆開 → 拿到**期中考考卷**，解鎖 A04「這是夢，對吧？」。考卷沒有其他用途。
  - 變成期中考考卷 →「你看到了考題，受到精神傷害」**-1 血**（每次變成都扣）。
- **月曆**（紅鯡魚）：「10 月 31 日被紅筆圈了起來」，看起來很像密碼 1031，其實那天是老師的生日。
  - 在大門試過 1031 失敗後再看月曆 → 旁邊多了一行小字「老師生日🎂」。

互動：X005～X008、X027、X032、X035

### 6.5 廁所

男女混合的廁所（避免分男女廁的麻煩），有幾間隔間。

- **馬桶**（每間都一樣）：
  - 人類 →「你舒服的上了個廁所」（無事發生）
  - 非人類形態 →「你被沖進了下水道……又爬了回來」**-1 血**
- **垃圾桶**：人類 →「你為什麼會想在這裡翻到東西」（無事發生）
- **儲物間門**：
  - 變成辦公桌抽屜的鑰匙碰門 → 門打開，裡面有一支**長竿子**。
  - 其他形態碰門 →「上鎖的門，應該是儲物間吧？」（無事發生）
- **高窗**：變成長竿子碰高窗 → 頂開窗戶，成功逃出 → **E03**「誰說一定要走正門」。

互動：X011～X015、X024

### 6.6 警衛室

**進入條件**：從走廊直接進入。

- **配電箱**：
  - 人類拉下總電閘 →「喀——整棟樓瞬間安靜了下來，門禁機的燈也熄了」。門禁斷電，**學院大門永久打不開**（學生證和密碼都失效），之後只剩 E03、E04、E05。**不能再推回去。**
  - 非人類形態碰配電箱 →「滋滋滋——你觸電了」**-1 血**。
- **監視器**：和監視器互動 → 切到俯視角，可以看到整張地圖；再互動一次 → 切回原視角。監視器不能變身。
- **一大串鑰匙圈**（紅鯡魚）：變成它可以碰所有的門，但每扇都打不開 →「你試了每一支鑰匙……沒有一支插得進去」。碰過所有的門（含之後新增的門）→ 解鎖 A07「鑰匙收藏家」。

互動：X022、X023、X025、X033、X034

## 7. 結局

| 結局 ID | 觸發方式 | 類型 | 範圍 | 劇情 |
|---|---|---|---|---|
| E01 | 變成學生證打開大門 | 好結局 | 該玩家 | 夢醒 |
| E02 | 輸入正確的大門密碼 | 好結局 | 該玩家 | 夢醒 |
| E03 | 用長竿子打開廁所高窗跳出去 | 好結局 | 該玩家 | 夢醒 |

### 劇情：夢醒（E01～E03）
眼前一片白光。我睜開眼睛，赫然發現自己竟然回到了原本的課堂裡。下課鐘聲響起，老師說：

> 「好，那我們今天就上到這邊，下課。」

我這才知道，原來剛剛的一切都是夢。

### 劇情：被叫醒（E04）
窗外透進清晨的陽光，我還是沒能離開學院。這時，有人拍了拍我的肩膀。我抬起頭，看見老師站在桌邊：

> 「同學，下課了喔，睡得很熟嘛。」

我這才知道，原來剛剛的一切都是夢，而且我整堂課都在睡。

### 壞結局（E05）
遊戲重啟，從第一關重新開始。

## 10. 實作備註

給實作人員的重點整理：

1. **大門密碼**：每局開始時亂數產生四位數（0000～9999），需**排除 1031**。遊戲內不得出現任何指向密碼的線索或提示。
2. **密碼扣血**：每次輸錯獨立判定，1/1000 機率 -1 血（機率暫定）。
3. **成就儲存**：只在同一次遊玩期間保留，不需寫入永久儲存；關閉或重新整理網頁即清空。
4. **自身互動**：骰子、時鐘需支援「與自己互動」的操作。
5. **物品唯一**：同一物品同時只能被一位玩家變身。
6. **電閘**：拉下後不可逆，學生證（X010）與密碼（X016）互動永久失效。
7. **多人**：玩家之間不能互動；逃出只影響該玩家，逃生方法可被其他玩家重複使用；E04、E05 套用到所有未逃出的玩家。
8. **生命值**：全隊共用，初始 5，沒有上限。
