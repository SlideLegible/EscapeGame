## 2. 遊戲大致玩法

### 核心機制：變身與互動
玩家不是「拿著」物品，而是**變成**物品。

1. **變身**：玩家與某個可變身的物品互動，就會變成那個物品。
2. **以該形態互動**：用目前的形態去和其他東西（物品、機關、場景物件）互動，觸發對應事件。
   - 例：變成電源線 → 把自己插進插座
3. **進入特殊地點**：某些地點以人類的體型去不了，或人類進去不合理，必須變成特定物品才能進入。
   - 例：變成一罐飲料 → 進到飲料機裡面

玩家的「形態」包含：人類（初始形態）以及所有可變身的物品。

### 變身規則
- **變回人類**：隨時可以，會回到人類身體所在的位置。
- **人類身體**：每位玩家各自有一個人類身體。第一次變身時，人類身體留在原地，不會跟著移動。
- **物品直接互換**：可以從一個物品形態直接變成另一個物品。原本的物品留在當時的位置與狀態（例：插在插座上的電源線，離開後仍插著）。
- **變身來源**：變身後，那個物品仍存在於場景中，玩家等於「成為」它本身。
- **生命值**：所有形態共用同一條生命值。
- **物品唯一**：每個物品同一時間只能被一位玩家變身；已被變身的物品，其他玩家無法再變成它。

### 互動可能的結果
| 結果類型 | 說明 |
|---|---|
| 獲得線索 | 得到解謎所需的資訊 |
| 出現新物品 | 場景中出現新物品，可再變身或用於後續互動 |
| 變身 | 玩家變成某個物品 |
| 進入特殊地點 | 以特定形態進入新的區域 |
| 推進故事線 | 揭露劇情片段 |
| 加血 | 回復玩家生命值 |
| 扣血 | 減少玩家生命值 |
| 其他 Buff／Debuff | 特殊狀態效果（待定義） |
| 搞怪／無效果 | 有趣的回饋但不影響進度 |

> 所有物品之間的互動組合與對應事件，詳見 **item_interactions.md**。

### 生命值規則
- **全隊共用一條生命值**：任何玩家扣血，都是扣全隊的血。
- 生命值歸零 → 全隊一起死亡，觸發「死亡」壞結局，遊戲重啟（見第 9 節）

### 時間規則
- 遊戲時限 30 分鐘，時間到即觸發「天亮」特殊好結局（E04）

### 無效組合
- 互動表中沒有定義的組合，一律顯示預設回應（詳見 item_interactions.md 第 6 節）

### 遊戲目標
- **主要目標**：逃出學院（任一好結局或特殊好結局即通關）
- **收集目標**：透過成就系統收集故事線索與各種結局（詳見第 10 節）

### 故事線索的取得方式
- 特定的物品互動
- 完成關卡後獲得
- 完成關卡這件事本身就是線索

每條故事線索都是一個成就，記錄在第 3 節的「故事線索總表」。

## 3. 故事背景

### 故事前提
- 主角身處一場**夢境**，密室就是這場夢。

### 主角
- 「我」是一名大學生。
- 正在**別的學院**上課（不是自己學院的學生）。

### 開場劇情
我在上課的時候睡著了。

醒來時，竟然已經是晚上。學院的門被鎖住了。我不是這個學院的學生，根本不知道他們晚上會鎖門。看起來只有**刷學生證**或**知道密碼**才能出去。

於是我開始了一連串闖關，想找到一張學生證或密碼。

### 現實事件
- 現實中：主角在課堂上睡著了，整場遊戲都是他的夢。
- 好結局時揭曉：醒來時仍在原本的課堂上，剛好下課。
