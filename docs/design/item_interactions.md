## 4. 互動表

| 互動 ID | 玩家形態 | 互動對象 | 事件類型 | 事件描述 | 變身結果 | 出現物品 | 生命值變化 | Buff／狀態 | 成就 | 前置條件 | 備註 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| X001 | F01 電源線 | S01 插座 | （待定） | 把自己插進插座 | | | | | | | 範例 |
| X002 | F02 飲料 | S02 飲料機 | 地點 | 進到飲料機裡面 | | | | | | | 範例，進入 L01 |

「成就」欄填入成就 ID：故事成就用 C01、C02…，搞怪成就用 A01、A02…，對應主劇本第 10 節的成就系統。

**事件類型代碼**
- `線索`：獲得線索
- `物品`：場景中出現新物品
- `變身`：玩家變成某個形態
- `地點`：進入特殊地點
- `劇情`：推進故事線
- `加血`／`扣血`：生命值變化
- `Buff`／`Debuff`：狀態效果
- `搞怪`：有趣但無實際效果
- `成就`：解鎖成就（故事或搞怪）
- 一次互動可同時有多種類型，用「、」分隔

## 6. 預設回應

沒有定義在互動表中的組合，統一使用以下回應：

- **呈現方式**：彈出文字框
- **生命值／形態／狀態**：皆無變化
- **文字內容**：

> [對象]紋絲不動，好像在嘲笑你：「你是認真的嗎？」

`[對象]` 替換為玩家互動的物品或場景物件名稱。
